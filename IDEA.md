# Идея — reuse-ideas-generator

**Гипотеза:** по одному фото ненужной вещи Claude Vision + structured output стабильно
выдаёт 5–7 **конкретных** полезных идей (продать / починить / переделать / отдать /
утилизировать) — достаточно полезных, чтобы это работало как демо/портфолио.

## Для кого
Демо/портфолио (Claude Vision + structured output + Telegram-бот). Конечный пользователь —
любой, кто сфоткал ненужную вещь и хочет идеи, что с ней сделать.

## Почему может взлететь
Интернет даёт общие советы, чат с LLM требует формулировать запрос вручную. Здесь одно
фото → структурированный результат: категория, резюме, 5–7 идей со шагами, оценкой затрат
и конкретным первым действием.

## Примеры (до 10)
5–10 **реальных** фото конкретных вещей, покрывающих категории модели:

- потёртая кожаная куртка (`clothing`);
- старый деревянный стул (`furniture`);
- нерабочий фен (`electronics`);
- треснувшая кружка (`dishes`);
- детская коляска (`children_items`);
- стопка книг / сломанные наушники / вышедшие из моды джинсы (`other`, смешанные).

## Как проверяю (prototype)
Прогнать эти 5–10 фото напрямую через Claude Messages API (vision) → JSON → форматированный
ответ. **Финальный артефакт**: для каждого фото список 5–7 идей со шагами, оценкой затрат
и первым действием. Руками через SDK, без aiogram/SQLite-обвязки.

## Препятствия
Карта граблей (обновляю по ходу):

- Claude неверно определяет вещь или её состояние по фото;
- идеи получаются общими («продай на Авито») вместо конкретных под состояние вещи;
- JSON-валидация падает → нужен repair-запрос; на двух неудачах — контролируемая ошибка;
- ракурс / качество / освещение фото;
- покрытие категорий (что попадает в `other`);
- какой system prompt даёт конкретику, а не воду.

## Критерий «prototype ✓»
На 5–10 реальных фото из разных категорий получаю валидный JSON и 5–7 идей, которые сам
оцениваю как **реально полезные** (а не общие), — на большинстве примеров.

## Что дальше
При подтверждении — `_reposcripts\repo.ps1 graduate reuse-ideas-generator` поднимает
build-гейт (SPECS + about/TASKS + бэкап). aiogram / SQLite / repair-loop / pytest — на
build. Детальная постановка сохранена в git-истории этого IDEA.md.

# reuse-ideas-generator

По фото ненужной вещи — конкретные идеи, как её **повторно использовать или переделать**.
Продажу и утилизацию сервис не предлагает: продукт сознательно сужен до реюза
([D-009](COMMON_DECISION.md)).

Заодно это площадка для эксперимента: двое пробуют парную агентную разработку и идут
от творческого хаоса к MVP — [INTENTION.md](INTENTION.md).

**Стадия: build** ([D-020](COMMON_DECISION.md)). Explore закончен, две независимые разведки
лежат в [research/](research/) — но кода сервиса всё ещё нет, а критерий «прототип ✓» ни разу
не проверен реальным прогоном модели. Переход к сборке этот риск не снял, а перенёс.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Сейчас `main.py` — заглушка: печатает пути и ничего не делает. Запросы пойдут через
OpenRouter ([D-010](COMMON_DECISION.md)), модель выбирается замером, а не назначается заранее.

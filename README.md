## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```

## Вход и выход

- `input/` — внешние входные данные.
- `output/` — результаты запусков.
- `config.yaml` — несекретная конфигурация.
- `.env` — локальные секреты и токены, не хранится в git.

# reuse-ideas-generator

По фото ненужной вещи — 5–7 конкретных идей, что с ней сделать: продать, починить,
переделать, отдать, утилизировать.

Заодно это площадка для эксперимента: двое пробуют парную агентную разработку и идут
от творческого хаоса к MVP — [INTENTION.md](INTENTION.md).

**Стадия: прототип.** Гипотеза ещё не проверена, кода сервиса пока нет.

## Что где

| Файл | Про что |
| --- | --- |
| [INTENTION.md](INTENTION.md) | Зачем всё это и кто участвует |
| [ROLES.md](ROLES.md) | Как делим роли (шаблон, не заполнен) |
| [TASK_DESC.md](TASK_DESC.md) | Гипотеза, примеры, критерий «прототип ✓» |
| [about/KNOWN_ISSUES.md](about/KNOWN_ISSUES.md) | Известные проблемы |
| [CHANGELOG.md](CHANGELOG.md) | История значимых изменений |
| `main.py`, `config.yaml`, `.env.example` | Заготовка запуска: конфиг несекретный, секреты — в `.env` |

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```

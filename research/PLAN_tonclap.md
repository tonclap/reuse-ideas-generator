## Что в TASK_DESC уже решено

Гипотеза, 6 категорий, критерий «прототип ✓» (валидный JSON и 5–7 полезных идей на
большинстве из 5–10 фото), список граблей, ограничение «руками через SDK, без aiogram и
SQLite». Это не пересматриваю.

## Чего в постановке нет — и что придётся решить в explore

1. **Фото не существует.** «5–10 реальных фото конкретных вещей» — их надо снять или найти.
   Это первый блокер, а не деталь: без набора проверять нечего.
2. **Схема ответа не описана.** Поля названы прозой («категория, резюме, идеи со шагами,
   оценкой затрат и первым действием») — точной JSON-схемы нет.
3. **«Конкретная идея» не операционализирована.** Критерий «сам оцениваю как реально
   полезные» — оценка задним числом. Если не зафиксировать признак заранее, любой результат
   можно подогнать под успех.
4. **Модель и параметры не выбраны.**

## Технические решения (предлагаю)

- **Модель — `claude-opus-5`** (vision + structured output, 1M контекст). Sonnet 5 дешевле,
  но на прототипе экономить не на чем: 8 фото — это 8 запросов.
- **Structured output — `output_config.format` с JSON-схемой**, а не «попроси вернуть JSON и
  распарси». Схема гарантируется на стороне API, и грабля «JSON-валидация падает → repair-запрос»
  из TASK_DESC на прототипе просто не возникает. Repair-loop остаётся на build — если понадобится.
- **Python + официальный SDK `anthropic`**, `client.messages.parse()` с Pydantic-моделью:
  ответ приходит уже провалидированным объектом.
- **Фото — base64** в блоке `image` (файлы локальные, Files API на прототипе не нужен).
- Ключ — в `.env` (уже в `.gitignore`), в git не попадает.

## Черновик схемы

```
category: enum[clothing, furniture, electronics, dishes, children_items, other]
item: str            # что это за вещь
condition: str       # состояние, видимое на фото
summary: str
ideas: [5..7] {
  action: enum[sell, repair, remake, give_away, recycle]
  title: str
  steps: [str]
  cost_estimate: str
  first_step: str    # одно конкретное действие на сегодня
}
```

## Признак «конкретной» идеи (черновик критерия шага 3)

Идея засчитывается, если выполнены **все три**:

1. привязана к тому, что видно на фото (состояние, материал, износ), а не подходит любой вещи
   этой категории;
2. `first_step` — действие, выполнимое сегодня без дополнительных решений;
3. `cost_estimate` — не «зависит от», а диапазон или «бесплатно».

«Продай на Авито» проваливает пункты 1 и 2 — это эталон отрицательного примера.
